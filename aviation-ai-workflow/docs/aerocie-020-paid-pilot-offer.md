# AeroCIE | Proposed 60-day paid evaluation

**Customer:** Aviation MGA, aviation coverholder or specialty underwriting desk.  
**Offer:** $2,500 total for a defined 60-day evaluation, payable under a signed statement of work.  
**Product evaluated:** AeroCIE general aviation submission evidence and MRO research pipeline, with a unified Power BI or HTML review dashboard.

## Proposed scope

- Up to 50 historic submission examples selected under a written sampling plan. First use an artificial dataset. Access to actual submissions requires a separate agreed data-handling plan, authority to process and appropriate contractual terms.
- Define the target adverse outcome and lookback window before running the model. Obtain outcomes that were known only *after* the submission date, while ensuring that the model uses only features available *at* that date.
- Map airframe attributes, pilot qualifications supplied by the customer, five-year claims/loss context, and permitted MRO source observations to documented feature fields.
- Run the same cases through the buyer's existing triage process or recorded historical baseline. Keep exact dataset version, label policy and review overrides.
- Deliver an evidence register, factor explanations, known/unknown outcome counts, false negative counts, a timed workflow comparison, an exception queue, and a documented follow-up plan.

### Schedule

| Days | Work product |
| --- | --- |
| 1–10 | Scope agreement, outcome definition, permissions, dataset field inventory and historical baseline |
| 11–25 | Source mapping, sample quality assessment, pipeline integration and human review |
| 26–45 | Retrospective comparison, blinded analyst timing exercise, calibration and error analysis |
| 46–60 | Results report, buyer review and decision on further evaluation or commercial subscription |

### Pilot scorecard

| Metric | Measurement |
| --- | --- |
| Case coverage | Records with sufficient source fields / total sample |
| Sources traceable | Reproducible origin/version and evidence status for each tested field |
| Adverse outcome sensitivity | Flagged adverse cases / adverse cases with known outcome |
| False negative count | Adverse cases labelled Quote by research triage |
| Precision / specificity | Calculated only where both positive and negative outcomes are known |
| Referral proportion | Cases needing analyst review / total cases |
| Analyst time saved | Observed paired processing minutes and percent change against baseline |
| Underwriter acceptance | Analyst approval/override reason for reviewed cases |
| Economics | Data, labor, implementation and subscription costs under buyer-supplied assumptions |

A 50-case sample is small. Confidence intervals, missing records, adverse-event base rates, selection bias, and change over time must accompany any headline statistic. A retrospective relationship between a warning and an adverse claim does not demonstrate that the claim could have been avoided, or that loss ratio improvement will occur. Do not promise a 50% reduction or a model that correctly predicts specific paid losses.

### Decision to expand

At day 60 the buyer can evaluate a full subscription against mutually defined criteria: actual workflow time improvement, accepted evidence quality, agreed error tolerance, procurement and data requirements, and budget. Proposed subscription reference price: **$5,000/month ($60,000/year)** for a mid-size desk, subject to scope, usage, source licensing and contracting. Any pilot-fee credit is negotiable and applies only if written into the executed agreement.

No pilot outcome guarantees a subscription, savings, or a future acquisition.

### Pilot preparation checklist

- Owner of budget and underwriting policy identified.
- Explicit scope and success criteria signed by both parties.
- Historical source permissions, privacy terms and minimization requirements agreed.
- Evidence and evaluation artifacts created from an approved dataset.
- Independent reviewer validates analytical findings and source lineage.
- Fee, term, invoicing, termination, handling of deliverables and liability are documented.
